## 현재 전략 — v4 거래량 모멘텀 + VWAP

### 핵심 개념

- **종목 선정**: 재무 필터 없음. 매 실행마다 거래량 Top20 동적 발굴
- **진입 판단**: **VWAP 이탈률 1차** + HA 패턴 보조 확인
- **청산**: 당일 13:00 전량 강제 청산 (오버나이트 리스크 제로)
- **Google Search**: 1회차(09:20)에만 시장 테마/이슈 파악

### 실행 구조

```
Cloud Scheduler (20회/일, 11분 간격, 09:20~13:00)
  → Cloud Run Job (main.py --once)
      → 세션 루프 5회 (루프 간 30초 슬립)
          ├─ [루프 1~5] Python 사전 체크 (get_balance + VWAP)
          │   ├─ TP/SL 조건 or 빈 슬롯 or 보유 종목 VWAP 음수 → Gemini 호출
          │   └─ 조건 없으면 스킵
          └─ 5루프 완료 후 최종 요약 LLM 1회 호출 → 세션 로그 기록
```

**실질 모니터링 주기**: 스케줄 11분 × 내부 5회 = **약 2분 간격**

### 스케줄 (11분 간격, cron KST)

| 회차 | 시간 | 역할 |
|---|---|---|
| 1 | 09:20 | 진입 — Google 검색 + Top20 스캔 |
| 2~8 | 09:31~10:37 | 오전 점검 — VWAP 0~+3% 확인 후 진입 |
| 9~15 | 10:48~11:54 | 오전 후반 — VWAP 0~+3% 조건 충족 시만 진입 |
| 16~19 | 12:05~12:38 | 정리 — VWAP 0~+2% 이내만 신규 진입 |
| 20 | 13:00 | **강제 청산 — 전량 매도** |

### 진입 기준 (VWAP 1차 + HA 보조)

**VWAP 이탈률** = (현재가 - VWAP) / VWAP × 100

**VWAP이 1차 판단 기준, HA는 강도 확인용 보조 지표**

| VWAP 이탈률 | HA 상태 | 판단 |
|---|---|---|
| 0% ~ +3% | 강한상승(윗꼬리 < 몸통×15%) | ✅ 최우선 매수 |
| 0% ~ +3% | 일반 양봉 | ✅ 매수 |
| 0% ~ +3% | 음봉 | ⚠️ 보류 (하락 반전 의심) |
| +3% 초과 | 무관 | ⚠️ 소량/보류 (고점 추격 위험) |
| 음수 | 무관 | ❌ 진입 금지 (관성 역행) |

**HA 분류**: 윗꼬리(또는 아랫꼬리) < 몸통 × 15% → "강한" 패턴

### 포지션 사이징 (VWAP 기반)

| 조건 | 비율 |
|---|---|
| VWAP 0~+3% + HA 강한상승 | 가용예수금의 40~50% |
| VWAP 0~+3% + 일반 양봉 | 가용예수금의 25~35% |
| VWAP +3% 초과 | 가용예수금의 10~15% |

```
매수금액 = 가용예수금 × 비율 ÷ 남은 슬롯 수
주문 수량 = 매수금액 ÷ 현재가 (소수점 버림)
```

### 포지션 교체 (예수금 부족 시)

아래 3가지 조건 충족 시 보유 종목 중 약한 종목을 청산하고 신규 매수 허용:

1. 신규 종목 VWAP 0~+3% (HA 조건 무관)
2. 가용예수금 < 필요금액의 50%
3. 현재 시각 12:00 이전

**청산 후보 우선순위**: VWAP 음수 종목 → 손실 종목 → VWAP 이탈률 낮은 종목

교체 후보가 없거나 모두 신규보다 VWAP 이탈률이 높으면 교체 안 함.

### 청산 조건

| 조건 | 기준 |
|---|---|
| 익절 (TP) | 수익률 +4% 이상 |
| 손절 (SL) | 수익률 -2.5% 이하 |
| 강제 청산 | 13:00 전량 |

### Python 사전 체크 (LLM 호출 게이트)

모든 루프에서 LLM 호출 전 Python이 먼저 판단:

```
포트폴리오 조회
├─ 보유 종목 TP/SL 조건 해당 → LLM 호출
├─ 빈 슬롯 있음 (보유 < MAX_POSITIONS) → LLM 호출
├─ 포지션 풀 + 보유 종목 중 VWAP < 0 → LLM 호출
└─ 위 조건 없음 → 스킵 (LLM 비용 절감)
```

### 파라미터 (config.py / deploy.yml)

```python
TAKE_PROFIT_PCT      = 4.0   # 익절 기준 (%)
STOP_LOSS_PCT        = 2.5   # 손절 기준 (%)
MAX_POSITIONS        = 5     # 최대 보유 종목
INNER_LOOP_COUNT     = 5     # 스케줄 1회당 내부 루프 수
INNER_LOOP_SLEEP_SEC = 90    # 첫 루프 후 슬립 (이후 루프는 30초)
```
