## v1 — 재무제표 기반 가치투자 (초기)

### 개요
KOSPI 우량주 20종목을 대상으로 재무제표를 분석해 저평가 종목에 투자.

### 워치리스트
KOSPI 우량주 20종목 (8개 섹터 고정)
- 반도체/전자: 삼성전자, SK하이닉스, LG전자
- 인터넷/플랫폼: NAVER, 카카오
- 자동차: 현대차, 기아, 현대모비스
- 2차전지/화학: LG에너지솔루션, 삼성SDI, LG화학
- 철강/소재: POSCO홀딩스, 고려아연
- 금융: KB금융, 신한지주, 하나금융지주
- 바이오: 삼성바이오로직스, 셀트리온
- 통신/지주: SK텔레콤, 삼성물산

### 매수 조건
- ROE ≥ 10%
- 부채비율 ≤ 150%
- 영업이익률 ≥ 5%
- PER이 업종 평균 이하

### 매도 조건
- 목표 수익률 +15% 달성 시 매도
- 손실 -8% 초과 시 손절

### 실행 스케줄
하루 3회 배치 실행 (09:10, 12:00, 14:30)

### 한계
- 재무제표는 분기 데이터 → 단기 가격 변동에 대응 불가
- 배치 실행 구조라 실시간 TP/SL 반응 불가
- 고정 워치리스트 → 그날의 주도 종목 놓칠 수 있음

## v2 — 하이킨아시 모멘텀 전략 (검토 중, 2026-05-02)

### 개요
재무지표를 제거하고, 거래량 상위 종목의 5분봉 하이킨아시 패턴으로 모멘텀 진입.
당일 청산 원칙으로 오버나이트 리스크 완전 제거.

### 종목 선정
- 매일 장 시작 후 거래량 상위 10개 종목을 실시간 조회
- 고정 워치리스트 없음

### 진입 조건
1. 장 시작 후 30분 관망 (09:00~09:30)
2. 5분봉 하이킨아시 캔들 기준으로 아래 패턴 확인:
   - **윗꼬리 달린 양봉 2개 연속** (HA_Close > HA_Open, HA_High > HA_Close)
3. 조건 충족 종목 매수

#### 하이킨아시 계산식
```
HA_Close = (Open + High + Low + Close) / 4
HA_Open  = (prev_HA_Open + prev_HA_Close) / 2
HA_High  = max(High, HA_Open, HA_Close)
HA_Low   = min(Low, HA_Open, HA_Close)
```

### 청산 조건
| 조건 | 기준 |
|------|------|
| 익절 | 수익률 +10% 달성 시 즉시 매도 |
| 손절 | 수익률 -5% 도달 시 즉시 매도 |
| 강제 청산 | 15:20 이전 잔여 포지션 전량 매도 (당일 청산 원칙) |

### 필요 변경사항

#### 신규 API 연동
- 거래량 상위 조회: KIS `FHPST01710000` (실시간 거래량 상위)
- 5분봉 조회: KIS `FHKST03010200` (주식 분봉)
- 하이킨아시 변환 로직 (Python 계산)
- 패턴 감지 로직 (연속 2개 조건)

#### 시스템 프롬프트 전면 교체
- 재무지표 판단 로직 제거
- 기술적 분석 지시로 교체

#### 강제 청산 스케줄 추가
- 15:20 실행 전용 Cloud Scheduler job 추가

### 아키텍처 이슈 및 해결 방안

**문제**: 현재 구조(하루 3회 배치)는 TP/SL을 실시간으로 감지 불가.
매수 후 다음 실행까지 최대 2~3시간 공백 → SL 돌파 후 방치 위험.

**해결 방안 비교**

| 방안 | 구현 난이도 | SL 반응 지연 | 비용 |
|------|------------|-------------|------|
| A) 배치 15분 간격 | 낮음 | 최대 15분 | 낮음 |
| B) 장중 루프 서비스 | 높음 | 5분 이내 | 중간 |

- **A안**: Cloud Scheduler 주기를 15분으로 변경. 현 구조 그대로 유지. 빠르게 적용 가능.
- **B안 (권장)**: 09:10에 시작해 15:20까지 루프 실행하는 Cloud Run Service로 전환. 5분마다 포지션 체크 → TP/SL 즉시 대응. 구조 변경 필요.
