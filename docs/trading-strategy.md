## v2 — 하이킨아시 모멘텀 전략 (검토 중, 2026-05-02)

### 개요
재무지표를 제거하고, 거래량 상위 종목의 5분봉 하이킨아시 패턴으로 모멘텀 진입.
당일 청산 원칙으로 오버나이트 리스크 완전 제거.

### 종목 선정
- 매일 장 시작 후 거래량 상위 10개 종목을 실시간 조회
- 고정 워치리스트 없음

### 진입 조건
1. 장 시작 후 30분 관망 (09:00~09:30)
2. 5분봉 하이킨아시 캔들 기준으로 아래 패턴 확인:
   - **윗꼬리 달린 양봉 2개 연속** (HA_Close > HA_Open, HA_High > HA_Close)
3. 조건 충족 종목 매수

#### 하이킨아시 계산식
```
HA_Close = (Open + High + Low + Close) / 4
HA_Open  = (prev_HA_Open + prev_HA_Close) / 2
HA_High  = max(High, HA_Open, HA_Close)
HA_Low   = min(Low, HA_Open, HA_Close)
```

### 청산 조건
| 조건 | 기준 |
|------|------|
| 익절 | 수익률 +10% 달성 시 즉시 매도 |
| 손절 | 수익률 -5% 도달 시 즉시 매도 |
| 강제 청산 | 15:20 이전 잔여 포지션 전량 매도 (당일 청산 원칙) |

### 필요 변경사항

#### 신규 API 연동
- 거래량 상위 조회: KIS `FHPST01710000` (실시간 거래량 상위)
- 5분봉 조회: KIS `FHKST03010200` (주식 분봉)
- 하이킨아시 변환 로직 (Python 계산)
- 패턴 감지 로직 (연속 2개 조건)

#### 시스템 프롬프트 전면 교체
- 재무지표 판단 로직 제거
- 기술적 분석 지시로 교체

#### 강제 청산 스케줄 추가

### 아키텍처 이슈 및 해결 방안

**문제**: 현재 구조(하루 3회 배치)는 TP/SL을 실시간으로 감지 불가.

## v3 — 하이브리드: LLM 판단 + Python 실행 (채택, 2026-05-02)

### 개요
LLM은 아침 1회 진입 판단(시장 맥락 + 패턴 평가 + 포지션 결정)에 집중하고,
TP/SL 모니터링과 강제 청산은 Python 루프로 처리.
LLM의 판단 능력과 Python의 실행 속도를 역할에 맞게 분리.

### 아키텍처

```
[LLM 판단 — 아침 1회]
  09:10 시작
    · 오늘 시장 분위기 판단 (급락장이면 진입 스킵)
    · 거래량 상위 10종목 조회
    · 각 종목 5분봉 HA 패턴 평가
    · 조건 충족 종목 중 가장 강한 것 선택
    · 예수금 대비 포지션 크기 결정
    · 매수 실행

[Python 루프 — 장중 지속]
  매수 후 ~ 15:20
    · 5분마다 현재가 조회
    · 수익률 >= +10% → 즉시 익절
    · 수익률 <= -5%  → 즉시 손절

  15:20 → 잔여 포지션 전량 강제 청산 후 종료
```

### LLM이 담당하는 판단

| 상황 | LLM 판단 내용 |
|------|--------------|
| 시장 전체 약세 | 오늘 진입 여부 결정 (스킵 가능) |
| 복수 후보 종목 | 가장 강한 모멘텀 종목 1개 선택 |
| 포지션 크기 | 예수금 대비 비율 결정 (보수/공격적) |
| 패턴 신뢰도 | HA 조건은 맞지만 흐름이 약하면 스킵 |

### Python이 담당하는 실행

| 작업 | 이유 |
|------|------|
| TP +10% 익절 | 속도가 생명, LLM 지연 불필요 |
| SL -5% 손절 | 룰 기반, 판단 여지 없음 |
| 15:20 강제 청산 | 시간 기반 트리거, LLM 불필요 |

### 향후 LLM 확장 포인트
- 뉴스 API 연동 시: 공시/호재/악재 반영한 진입 판단
- 실적 발표 캘린더 연동 시: 발표일 앞두면 진입 스킵
- 코스피 지수 흐름 분석: 시장 전체 방향성 판단

### 청산 조건
| 조건 | 기준 | 처리 |
|------|------|------|
| 익절 | +10% | Python 즉시 실행 |
| 손절 | -5% | Python 즉시 실행 |
| 강제 청산 | 15:20 | Python 즉시 실행 |

### 필요 변경사항

#### 신규 API 연동 (broker/kis.py)

### HA 패턴 분류 기준

분봉: **3분봉** (1분봉 30개 → 3분봉 10개로 집계, `broker/kis.py`)

```
양봉(ha_close > ha_open):
  윗꼬리 < 몸통 × 15%  →  강한상승
  윗꼬리 ≥ 몸통 × 15%  →  상승저항(윗꼬리)

음봉(ha_close ≤ ha_open):
  아랫꼬리 < 몸통 × 15%  →  강한하락
  아랫꼬리 ≥ 몸통 × 15%  →  하락저지(아랫꼬리)
```

### 진입 기준 (HA + VWAP 복합 판단)

**VWAP 이탈률** = (현재가 - VWAP) / VWAP × 100

| HA 패턴 | VWAP 이탈률 | 진입 판단 |
|---|---|---|
| 강한상승 1봉+ | 0% ~ +3% | ✅ 적극 매수 |
| 강한상승 1봉+ | +3% 초과 | ⚠️ 소량 또는 보류 (고점 위험) |
| 강한상승 1봉+ | 음수 | ⚠️ 보류 (VWAP 미돌파) |
| 상승저항(윗꼬리 양봉) | 0% ~ +2% | ⚠️ 소량 진입 가능 |
| 상승저항(윗꼬리 양봉) | 그 외 | ❌ 보류 |
| 음봉 또는 혼합 | 무관 | ❌ 매수 금지 |

> HA 단독 판단에서 **HA + VWAP 복합 판단**으로 전환. 강한상승 2봉+ 기준을 1봉+로 완화하되 VWAP 이탈률로 진입 품질 필터링.

### 매수량 배분 (포지션 사이징)

```
매수금액 = 가용예수금 × 비율 ÷ 남은 슬롯 수
주문 수량 = 매수금액 ÷ 현재가 (소수점 버림)
```

| 조건 | 예수금 배분 비율 |
|---|---|
| HA강 + VWAP 0~+3% | 40~50% (슬롯 1개 기준) |
| HA강 + VWAP 그 외 / HA중 | 20~30% |
| 상승저항 + VWAP 0~+2% | 10~15% |

복수 종목 진입 시 가용 예수금을 슬롯 수로 나눠 분산.

---

### 청산 조건

| 조건 | 기준 | 처리 |
|---|---|---|
| 익절 | 수익률 **+4%** 이상 | LLM 판단으로 매도 |
| 손절 | 수익률 **-2.5%** 이하 | LLM 판단으로 즉시 매도 |
| 추세 전환 | HA 음봉 전환 + 수익권 | LLM 판단으로 매도 고려 |
| 강제 청산 | **13:00** | 보유 전종목 무조건 전량 매도 |

> TP/SL 기본값은 `config.py`의 `TAKE_PROFIT_PCT=4.0`, `STOP_LOSS_PCT=2.5`로 조정.
