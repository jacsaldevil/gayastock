## v2 — 하이킨아시 모멘텀 전략 (검토 중, 2026-05-02)

### 개요
재무지표를 제거하고, 거래량 상위 종목의 5분봉 하이킨아시 패턴으로 모멘텀 진입.
당일 청산 원칙으로 오버나이트 리스크 완전 제거.

### 종목 선정
- 매일 장 시작 후 거래량 상위 10개 종목을 실시간 조회
- 고정 워치리스트 없음

### 진입 조건
1. 장 시작 후 30분 관망 (09:00~09:30)
2. 5분봉 하이킨아시 캔들 기준으로 아래 패턴 확인:
   - **윗꼬리 달린 양봉 2개 연속** (HA_Close > HA_Open, HA_High > HA_Close)
3. 조건 충족 종목 매수

#### 하이킨아시 계산식
```
HA_Close = (Open + High + Low + Close) / 4
HA_Open  = (prev_HA_Open + prev_HA_Close) / 2
HA_High  = max(High, HA_Open, HA_Close)
HA_Low   = min(Low, HA_Open, HA_Close)
```

### 청산 조건
| 조건 | 기준 |
|------|------|
| 익절 | 수익률 +10% 달성 시 즉시 매도 |
| 손절 | 수익률 -5% 도달 시 즉시 매도 |
| 강제 청산 | 15:20 이전 잔여 포지션 전량 매도 (당일 청산 원칙) |

### 필요 변경사항

#### 신규 API 연동

- 5분봉 조회: KIS `FHKST03010200` (주식 분봉)

- 패턴 감지 로직 (연속 2개 조건)

#### 시스템 프롬프트 전면 교체
- 재무지표 판단 로직 제거
- 기술적 분석 지시로 교체

#### 강제 청산 스케줄 추가

### 아키텍처 이슈 및 해결 방안

## v3 — 하이브리드: LLM 판단 + Python 실행 (채택, 2026-05-02)

### 개요
LLM은 아침 1회 진입 판단(시장 맥락 + 패턴 평가 + 포지션 결정)에 집중하고,
TP/SL 모니터링과 강제 청산은 Python 루프로 처리.
LLM의 판단 능력과 Python의 실행 속도를 역할에 맞게 분리.

### 아키텍처

```
[LLM 판단 — 아침 1회]
  09:10 시작
    · 오늘 시장 분위기 판단 (급락장이면 진입 스킵)
    · 거래량 상위 10종목 조회
    · 각 종목 5분봉 HA 패턴 평가
    · 조건 충족 종목 중 가장 강한 것 선택
    · 예수금 대비 포지션 크기 결정
    · 매수 실행

[Python 루프 — 장중 지속]
  매수 후 ~ 15:20
    · 5분마다 현재가 조회
    · 수익률 >= +10% → 즉시 익절
    · 수익률 <= -5%  → 즉시 손절

  15:20 → 잔여 포지션 전량 강제 청산 후 종료
```

### LLM이 담당하는 판단

| 상황 | LLM 판단 내용 |
|------|--------------|
| 시장 전체 약세 | 오늘 진입 여부 결정 (스킵 가능) |
| 복수 후보 종목 | 가장 강한 모멘텀 종목 1개 선택 |
| 포지션 크기 | 예수금 대비 비율 결정 (보수/공격적) |
| 패턴 신뢰도 | HA 조건은 맞지만 흐름이 약하면 스킵 |

### Python이 담당하는 실행

| 작업 | 이유 |
|------|------|
| TP +10% 익절 | 속도가 생명, LLM 지연 불필요 |
| SL -5% 손절 | 룰 기반, 판단 여지 없음 |
| 15:20 강제 청산 | 시간 기반 트리거, LLM 불필요 |

### 향후 LLM 확장 포인트
- 뉴스 API 연동 시: 공시/호재/악재 반영한 진입 판단
- 실적 발표 캘린더 연동 시: 발표일 앞두면 진입 스킵
- 코스피 지수 흐름 분석: 시장 전체 방향성 판단

### 청산 조건
| 조건 | 기준 | 처리 |
|------|------|------|
| 익절 | +10% | Python 즉시 실행 |
| 손절 | -5% | Python 즉시 실행 |
| 강제 청산 | 15:20 | Python 즉시 실행 |

### 필요 변경사항

#### 신규 API 연동 (broker/kis.py)

재무제표 기반 우량주 필터와 하이킨아시 기술적 분석을 결합해 매매 판단을 내립니다.
이것은 실전 투자입니다.

## ⚠️ 절대 규칙 — 당일 청산 (최우선)
오전에 매수한 종목은 반드시 당일 15:20 이전에 전량 매도합니다.

재무 기준 미달 종목은 차트 신호와 무관하게 매수하지 않습니다.

## 하이킨아시 — 진입 타이밍 판단
재무 기준을 통과한 종목에 대해 get_heikin_ashi_candles를 호출해 5분봉 하이킨아시를 확인합니다.
하이킨아시는 진입 타이밍 참고 지표입니다. 최종 결정은 당신이 종합적으로 내립니다.

해석 기준:
- 강한상승 (윗꼬리 없는 양봉) 연속: 모멘텀 강함 → 매수 적극 고려
- 상승저항 (윗꼬리 달린 양봉): 저항 발생 → 신중하게 판단
- 강한하락 (아랫꼬리 없는 음봉) 연속: 하락 추세 → 매수 금지
- 하락저지 (아랫꼬리 달린 음봉): 추세 약화 → 보유 중이면 매도 고려

## 매도 기준
- 수익률 +15% 이상: 익절 적극 고려
- 수익률 -8% 이하: 손절 (추가 손실 방지)
- 하이킨아시 음봉 전환 + 수익권: 추세 약화 시 매도 고려
- 15:10 이후: 당일 매수분 즉시 전량 매도 (절대 규칙)

## 분석 절차
1. get_portfolio → 보유 종목 및 수익률 확인
2. 현재 시각이 15:10 이후이거나 보유 종목 중 손절/익절 조건 해당 시 → 즉시 sell_stock
3. 분석 대상 종목별:
   a. get_financial_statements → ROE/부채비율/영업이익률 확인 (그라운드 룰 체크)
   b. 재무 기준 통과 시 → get_stock_price → 현재가 확인
   c. get_heikin_ashi_candles → 5분봉 하이킨아시 패턴 분석
   d. 매수/보류 판단 및 재무지표 + 하이킨아시 근거 명시
4. 매수 시 buy_stock, 매도 시 sell_stock 실행

## 주의사항
- 재무 기준 미달 종목은 절대 매수하지 마세요.
- 예수금이 부족하면 매수하지 마세요.
- 최대 5개 종목까지만 보유합니다.
- 불확실하면 HOLD가 손실보다 낫습니다. 단, 당일 청산 규칙은 불확실성과 무관하게 반드시 지킵니다.
- 매수 근거에는 반드시 재무지표 수치와 하이킨아시 패턴을 포함하세요.
```

```

### 매수량 배분 (포지션 사이징)

#### 기본 원칙
- **예수금 100% 사용 가능** (공격적 운용)
- **동시 보유 최대 5종목** (Top5 전부 신호 나오면 전부 진입 가능)
- HA 신호 강도에 따라 비율 차등 배분

#### 1단계: HA 강도별 기본 비율

| HA 패턴 | 예수금 배분 비율 |
|---|---|
| 강한상승 2봉 이상 연속 | 40~50% |
| 강한상승 1봉 | 20~30% |
| 상승저항(윗꼬리 양봉) | 10~15% |

#### 2단계: 리스크 검증

```
(매수금액 × 손절률 2.5%) ≤ 예수금의 5% 이내

예) 예수금 100만원
  → 1종목 최대 손실 허용: 5만원
  → 최대 매수금액: 5만 ÷ 2.5% = 200만원 → 예수금 100만원 이하이므로 제약 없음
```

#### 복수 종목 배분 예시

```
신호 종목이 3개인 경우 (예수금 100만원):

종목A (강한상승 2봉): 45만원 (45%)
종목B (강한상승 1봉): 30만원 (30%)
종목C (상승저항):     15만원 (15%)
현금 유보:           10만원 (10%)
```

#### LLM 판단 요소
1. **HA 패턴 강도** — 신호가 강할수록 비중 확대
2. **거래량 순위** — 1위 종목에 약간 가중 (시장 집중도 반영)
3. **현재 보유 종목 수** — 이미 보유 중이면 신규 비중 조정
4. **전체 시장 분위기** — 전반적 하락장이면 전체 비중 50% 이하로 축소
