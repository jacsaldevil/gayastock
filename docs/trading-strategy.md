## 현재 전략 — v4 거래량 모멘텀 + VWAP

### 핵심 개념

- **종목 선정**: 재무 필터 없음. 매 실행마다 거래량 Top10 동적 발굴
- **진입 판단**: HA 패턴(3분봉) + VWAP 이탈률 복합 신호
- **청산**: 당일 13:00 전량 강제 청산 (오버나이트 리스크 제로)
- **Google Search**: 1회차(09:20)에만 시장 테마/이슈 파악

### 실행 구조

```
Cloud Scheduler (20회/일, 11분 간격, 09:20~13:00)
  → Cloud Run Job (main.py --once)
      → 내부 루프 4회 (1.5분 슬립)
          → Python 사전 체크 (get_balance)
              ├─ TP/SL 조건 해당 or 빈 슬롯 있음 → Gemini 호출
              └─ 포지션 풀 + TP/SL 없음 → 스킵
```

**실질 모니터링 주기**: 11분 ÷ 4회 = **약 2.5분**

### 스케줄 (11분 간격, cron KST)

| 회차 | 시간 | 역할 |
|---|---|---|
| 1 | 09:20 | 진입 — Google 검색 + Top10 스캔 |
| 2~8 | 09:31~10:37 | 오전 점검 — HA강 1봉+ + VWAP 확인 |
| 9~15 | 10:48~11:54 | 오전 후반 — HA강 1봉+ + VWAP 0~+3% 모두 충족 |
| 16~19 | 12:05~12:38 | 정리 — HA강 1봉+ + VWAP 0~+2% 이내만 |
| 20 | 13:00 | **강제 청산 — 전량 매도** |

### 진입 기준 (HA + VWAP)

**VWAP 이탈률** = (현재가 - VWAP) / VWAP × 100

| HA 패턴 | VWAP 이탈률 | 판단 |
|---|---|---|
| 강한상승 1봉+ | 0~+3% | ✅ 적극 매수 |
| 강한상승 1봉+ | +3% 초과 | ⚠️ 소량/보류 |
| 강한상승 1봉+ | 음수 | ⚠️ 보류 |
| 상승저항(윗꼬리) | 0~+2% | ⚠️ 소량 가능 |
| 상승저항(윗꼬리) | 그 외 | ❌ 보류 |
| 음봉/혼합 | 무관 | ❌ 금지 |

**HA 분류**: 윗꼬리(또는 아랫꼬리) < 몸통 × 15% → "강한" 패턴

### 포지션 사이징

| 조건 | 비율 |
|---|---|
| HA강 + VWAP 0~+3% | 가용예수금의 40~50% |
| HA강 + VWAP 기타 / HA중 | 가용예수금의 20~30% |
| 상승저항 + VWAP 0~+2% | 가용예수금의 10~15% |

```
매수금액 = 가용예수금 × 비율 ÷ 남은 슬롯 수
주문 수량 = 매수금액 ÷ 현재가 (소수점 버림)
```

### 청산 조건

| 조건 | 기준 |
|---|---|
| 익절 | 수익률 +4% 이상 |
| 손절 | 수익률 -2.5% 이하 |
| 추세 전환 | HA 음봉 + 수익권 |
| 강제 청산 | 13:00 전량 |

### 파라미터 (config.py)

```python
TAKE_PROFIT_PCT      = 4.0   # 익절 기준 (%)
STOP_LOSS_PCT        = 2.5   # 손절 기준 (%)
MAX_POSITIONS        = 5     # 최대 보유 종목
INNER_LOOP_COUNT     = 4     # 스케줄 1회당 내부 루프 수
INNER_LOOP_SLEEP_SEC = 90    # 루프 간 슬립 (초)
```
