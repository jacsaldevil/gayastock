# ADR-003: Streamlit 대시보드 채택

- **상태**: Accepted
- **날짜**: 2026-05-01

## 배경

에이전트의 포트폴리오 현황, 매매 이력, 판단 로그를 시각화할 대시보드가 필요했다. KIS 모의투자 HTS에서는 에이전트의 판단 근거나 AI 로그를 볼 수 없어 별도 구현이 필요했다.

## 결정

**Streamlit으로 대시보드를 구현한다.**

3개 페이지로 구성:
- **포트폴리오**: 실시간 잔고, 보유종목 테이블, 비중 파이차트, 수익률 막대차트
- **매매 이력**: 에이전트가 실행한 매수/매도 이력, 일별 금액 차트
- **에이전트 로그**: 실행 회차별 Claude 판단 요약 + 포트폴리오 스냅샷

## 검토한 대안

| 방식 | 탈락 이유 |
|------|-----------|
| FastAPI + React/Next.js | 구현량 많음, 백엔드/프론트 분리 유지 비용 |
| Grafana | 데이터소스 연동 설정 필요, 텍스트 기반 AI 로그 표시 부적합 |
| KIS HTS 내장 | AI 판단 근거, 에이전트 로그 표시 불가 |
| Streamlit | **채택**: Python만으로 완결, Plotly 차트 내장, 빠른 프로토타이핑 |

## 결과

- **긍정적**: 에이전트와 동일한 Python 환경, 추가 언어 불필요, Cloud Run 단일 컨테이너로 배포 가능
- **부정적**: 복잡한 인터랙션(실시간 WebSocket 스트리밍, 커스텀 URL 라우팅)에는 한계
- **제약**: 다수 사용자 동시 접속 시 세션 격리 이슈 가능. 개인용 또는 소규모 팀 용도에 적합

## 향후

사용자 인증, 실시간 체결 알림, 커스텀 도메인 라우팅이 필요해지면 FastAPI + Next.js 전환을 검토한다.
