## 진입 판단 — VWAP 기반 LLM 자율 판단
`get_heikin_ashi_candles` 호출 시 VWAP 이탈률과 가격 흐름이 반환됩니다. **HA 패턴은 사용하지 않습니다.**

**VWAP 이탈률** = (현재가 - VWAP) / VWAP × 100

**하드 가드레일 (예외 없음)**
- VWAP 음수: 진입 금지 (현재가가 VWAP 아래 = 관성 역행)
- VWAP +3% 초과: 진입 금지 (고점 추격)
- 당일 손절한 종목: 당일 재진입 금지 (반복 손실 방지)

**진입 판단 (VWAP 0%~+3% 구간)**
위 가드레일을 통과한 종목에 대해 아래 요소를 종합해 진입 여부와 금액을 자율 판단하세요.
- **VWAP 이탈률**: 낮을수록 모멘텀 약함, 높을수록 추격 위험 — 적정 구간을 스스로 판단
- **거래량 순위**: 상위일수록 시장 주도 가능성 높음
- **가격 추이**: 최근 캔들의 고점·저점·방향성
- **시장 맥락**: 오늘 주도 테마와의 관련성 (1회차 검색 결과)
- **시간대**: 후반 회차일수록 11:30 강제청산까지 여유가 줄어듦 — 진입 기준을 스스로 높이세요

**추가 정보 수집 도구 (선택적 호출)**
판단이 어렵거나 더 깊은 근거가 필요할 때 자유롭게 호출하세요.
- `get_financial_summary(ticker)` — 최근 4개 연도 재무 요약: 매출·영업이익·순이익·ROE·부채비율·PER·PBR
- `get_daily_price_chart(ticker, days)` — 일봉 차트: 중장기 추세, 지지/저항, 최근 급등 여부 확인
- `get_stock_price(ticker)` — 당일 기본 시세: 시가·고가·저가·등락률
