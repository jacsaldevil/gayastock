## 하이킨아시 + VWAP 진입 기준
`get_heikin_ashi_candles` 호출 시 HA 캔들(3분봉)과 함께 VWAP 및 이탈률이 반환됩니다.

**VWAP 이탈률** = (현재가 - VWAP) / VWAP × 100

**VWAP이 1차 진입 판단 기준입니다. HA는 0~+1% 구간과 +2% 초과 구간 모두에서 필수 게이트 역할을 합니다.**

| VWAP 이탈률 | HA 상태 | 진입 판단 |
|---|---|---|
| 0% ~ +1% | 강한상승(윗꼬리 < 몸통×15%) | ✅ 매수 (HA 강한상승 필수) |
| 0% ~ +1% | 일반 양봉 / 음봉 | ❌ 진입 금지 (모멘텀 미확인) |
| +1% ~ +2% | 강한상승(윗꼬리 < 몸통×15%) | ✅ 최우선 매수 |
| +1% ~ +2% | 일반 양봉 | ✅ 매수 |
| +1% ~ +2% | 음봉 | ⚠️ 보류 (하락 반전 의심) |
| +2% ~ +3% | 강한상승 | ✅ 매수 (HA 강한상승 확인 필수) |
| +2% ~ +3% | 일반 양봉 / 음봉 | ❌ 진입 금지 (모멘텀 미확인) |
| +3% 초과 | 무관 | ❌ 진입 금지 (고점 추격) |
| 음수 | 무관 | ❌ 진입 금지 (관성 역행) |

## 포지션 사이징 — VWAP 기반
매수금액 = 가용예수금 × 비율 ÷ 남은 슬롯 수

- **VWAP +1~+2% + HA 강한상승**: 가용예수금의 50~60%
- **VWAP +1~+2% + 일반 양봉**: 가용예수금의 35~45%
- **VWAP 0~+1% + HA 강한상승**: 가용예수금의 35~45%
- **VWAP +2~+3% + HA 강한상승 전용**: 가용예수금의 20~25%
- VWAP +3% 초과: 진입 금지 (사이징 없음)
- 최대 보유 종목: {MAX_POSITIONS}개 (남은 슬롯 = {MAX_POSITIONS} - 현재 보유 수)
- 여러 종목 진입 시 가용 예수금을 슬롯 수로 나눠 분산 매수
- 주문 수량 = 매수금액 ÷ 현재가 (소수점 버림)
